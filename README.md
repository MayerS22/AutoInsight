' AutoInsight-GP

' ===========================
' 📌 Project Overview
' ===========================
' AutoInsight is an advanced platform designed to assist businesses in navigating 
' challenges related to layoffs and restructuring. It leverages data analysis, 
' predictive forecasting, and machine learning models to support decision-making, 
' reducing reliance on human intervention.

' ===========================
' 🚀 Features
' ===========================
' ✔ Data-Driven Insights – Analyze key metrics and trends for informed decision-making.
' ✔ Machine Learning Forecasting – Predict workforce needs and optimize restructuring plans.
' ✔ Intuitive Dashboard – Interactive and user-friendly UI for seamless navigation.
' ✔ Real-Time Analytics – Stay updated with live data processing.

' ===========================
' 🛠 Tech Stack
' ===========================
' 🔹 Frontend: React, Vite, Tailwind CSS
' 🔹 State Management: Redux

' ===========================
' ⚙ Installation & Setup
' ===========================
' Follow these steps to set up the project locally:

' Step 1: Clone the Repository
' -------------------------------------
' git clone https://github.com/MayerS22/AutoInsight.git
' cd AutoInsight
' cd frontend
' npm install
' npm run dev

' Step 2: Run the Application
' -------------------------------------
' After running "npm run dev", open your browser and navigate to:
' http://localhost:3000/
